## 三、PCB 设计要点

### 3.1 层叠设计

**推荐 6 层板**：

```
┌─────────────────────┐
│     L1 - 信号层      │ ← CPU、DDR 走线
├─────────────────────┤
│     L2 - GND         │ ← 完整地平面
├─────────────────────┤
│     L3 - 信号层      │ ← 内部信号
├─────────────────────┤
│     L4 - 电源层      │ ← 电源分割
├─────────────────────┤
│     L5 - GND         │ ← 完整地平面
├─────────────────────┤
│     L6 - 信号层      │ ← 底部走线
└─────────────────────┘
```

**关键点**：
- L2、L5 必须是完整地平面
- DDR 信号走 L1/L6，参考 L2/L5
- 高速信号不要跨分割

### 3.2 布局要点

**参考位置**：REF-29364_B.pdf

| 区域 | 布局要求 |
|------|---------|
| **CPU** | 居中，周围留出走线空间 |
| **DDR** | 紧靠 CPU，走线尽量短 |
| **eMMC** | 紧靠 CPU，走线尽量短 |
| **电源** | 靠近 CPU 电源引脚 |
| **晶振** | 靠近 CPU 时钟引脚，远离干扰源 |
| **去耦电容** | 紧靠电源引脚，0402 封装 |

### 3.3 布线要点

| 信号类型 | 阻抗 | 等长要求 | 备注 |
|---------|------|---------|------|
| DDR 数据线 | 50Ω | <5mil | 与 DQS 同组 |
| DDR 地址线 | 50Ω | <10mil | 与 CLK 同组 |
| DDR 时钟 | 100Ω 差分 | — | 差分对 |
| eMMC 数据线 | 50Ω | <10mil | 与 CMD 同组 |
| USB | 90Ω 差分 | — | 差分对 |
| 以太网 | 100Ω 差分 | — | 差分对 |

### 3.4 关键设计规则

1. **电源完整性**：
   - 每个电源引脚放置 100nF 去耦电容
   - 大电流电源放置 10uF 电容
   - 电源走线要宽（至少 15mil/A）

2. **信号完整性**：
   - DDR 走线不要有直角
   - 差分对间距保持一致
   - 高速信号不要跨分割

3. **EMC 设计**：
   - GND 平面要完整
   - 对外接口放置 TVS
   - 时钟信号包地处理

## 六、调试要点

### 6.1 上电前检查

1. **目视检查**：
   - 焊接是否虚焊、连锡
   - 器件方向是否正确

2. **电源检查**：
   - 用万用表测量各电源对地电阻
   - 确认没有短路

3. **阻抗检查**：
   - DDR 电源阻抗
   - CPU 核心电源阻抗

### 6.2 上电测试

1. **第一步：电源测试**
   - 按顺序上电：3.3V → 1.2V → 1.35V
   - 测量各电源电压是否正确
   - 观察电源纹波（示波器）

2. **第二步：时钟测试**
   - 测量 24MHz 晶振是否起振
   - 测量 32.768kHz 晶振是否起振

3. **第三步：启动测试**
   - 连接串口，观察启动信息
   - 确认 Boot ROM 正常

### 6.3 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 无法上电 | 电源短路 | 检查焊接，测量阻抗 |
| 无串口输出 | 时钟未起振 | 检查晶振、负载电容 |
| DDR 初始化失败 | 走线问题 | 检查等长、阻抗 |
| eMMC 识别失败 | 电源不稳 | 检查电源纹波 |

## 八、设计建议

### 8.1 第一次设计的建议

1. **先抄后改**：
   - 完全复制 NXP 官方核心板设计
   - 验证通过后再根据需求修改

2. **简化设计**：
   - 先不要加太多外设
   - 确保最小系统能启动

3. **预留扩展**：
   - 预留 GPIO、UART、I2C、SPI 接口
   - 预留调试接口（JTAG、SWD）

### 8.2 与正点原子底板配合

你的核心板需要插到正点原子底板上验证，需要注意：

| 接口 | 对应关系 | 备注 |
|------|---------|------|
| **电源** | 底板供电 → 核心板 | 确认电压一致 |
| **串口** | 底板 USB → 核心板 UART | 调试用 |
| **启动** | 底板 SD 卡 → 核心板 USDHC | 启动用 |
| **LCD** | 底板 LCD → 核心板 LCD 接口 | 显示验证 |
| **按键** | 底板按键 → 核心板 GPIO | 输入验证 |

### 8.3 设计周期预估

| 阶段 | 时间 | 说明 |
|------|------|------|
| 原理图设计 | 3-5天 | 参考官方设计 |
| PCB 布局 | 5-7天 | DDR 走线是重点 |
| PCB 布线 | 3-5天 | 等长、阻抗控制 |
| 打样等待 | 5-7天 | 嘉立创打样 |
| 焊接调试 | 2-3天 | 电源、时钟、启动 |
| **总计** | **18-27天** | — |
