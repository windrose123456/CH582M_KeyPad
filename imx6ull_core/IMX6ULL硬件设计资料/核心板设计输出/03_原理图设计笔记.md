## 页 3：电源树

```
5V_IN ──┬── [RT9169-33] ────────────── VDD_SNVS_IN (3.3V/100mA, Iq=4µA)
        │         └── D102/D103 RB521 ── BT1 纽扣电池（或 R≥400Ω）
        │
        ├── [MP2144] ──────────────── DCDC_3V3 (3.3V/2A) ──┬── NVCC_GPIO/ENET/LCD/UART
        │        EN ← VIN               PG=DCDC_3V3_PG      ├── eMMC VCC
        │                                                    ├── 复位芯片、拨码
        │                                                    └── 后级使能
        ├── [AP3401 #1] ───────────── VDDARM_IN / VDD_SOC_IN (1.35V/1A)
        │        EN ← DCDC_3V3_PG      FB: R1=125k R2=100k（DVFS 可切换 1.275/1.4）
        │
        ├── [AP3401 #2] ───────────── NVCC_DRAM (1.35V/1A)
        │        EN ← DCDC_3V3_PG
        │
        ├── [RT9169-18] ───────────── 1.8V ── eMMC VCCQ / NVCC_NAND
        │
        ├── [RT9193-33] ───────────── VDDA_ADC_3P3 (3.3V/300mA)
        │
        └── [UM1750S-00 / SY6280] ─── NVCC_SD (3.3V/1.8V 切换)
```

### 必须遵守（datasheet §4.2）

| 规则 | 实现手段 |
|------|---------|
| VDD_SNVS_IN 最先上电 | 独立 LDO 直挂 5V，不使能控制；或常开电池 |
| VDD_HIGH_IN 先于 VDD_SOC_IN | DCDC_3V3_PG → 使能 1.35V DCDC |
| POR_B 保持到全部电源稳定 | UM803 监控 3.3V，RC 延伸 + 可选第二级监控 |
| VDD_SNVS_IN 最后掉电 | 独立 LDO；5V 掉电后电池接管 |
| 无反向灌电 | 1.8V/3.3V 共载器件加肖特基隔离或负载开关 |
| IO 电源关断时禁止外部驱动 | 底板设计约束写入接口文档 |

### 电源树页还要画

- 每轨测试点 TP_5V / TP_3V3 / TP_1V35_CPU / TP_1V35_DRAM / TP_1V8 / TP_SNVS
- 测流电阻位 R729/R728/R732（默认 0Ω，可换 0.02Ω 量电流）
- PG 逻辑：`DCDC_3V3_PG` 汇总后去使能后级；可加 LED
- 输入保护：5V 反接二极管/TVS + 自恢复保险丝（可选）

### 等长规则（写入 PCB 规则）

| 组 | 相对 | 公差 |
|----|------|------|
| DQ[0:7] | DQS0 | ±5 mil |
| DQ[8:15] | DQS1 | ±5 mil |
| DQS0 两线对内 | — | ±5 mil |
| DQS1 两线对内 | — | ±5 mil |
| ADDR/CMD/BA/RAS/CAS/WE/CS/ODT/CKE | CLK | ±10 mil |
| CLK 对内 | — | ±5 mil |
| Byte lane 0 vs 1 | — | ±50 mil |

### 原理图细节

- DRAM_VREF：10k/10k 分压从 1.35V，中点 + 0.22µF（EVK C202）；**不要接 CPU 侧 VREF 以外的负载**
- 不要板级端接（EVK 无 VTT）；ODT 由软件配
- 保留 R/C 可调位：DQ 源端串阻 0–33Ω footprint（首版 0Ω）
- NC 球按 micron ball map 处理

## 页 10：电源管理明细

每路 DCDC 一页内画清：
- 输入电容 / 电感（MP2144: 1µH 等按 datasheet）/ 输出电容
- FB 分压电阻精确值 + 1%
- EN/PG 网络
- 软启动 / 补偿（按芯片手册）
- 电源指示 LED（可选）

**DVFS 双电压档**（EVK 做法）：

```
Vo = 0.6 × (R1+R2)/R2
档位1 (528MHz): R1=113k → 1.275V
档位2 (792MHz): R1=125k → 1.35V
切换: MOSFET 并联 R1 的一部分，GPIO_DVFS 控制
```

792 MHz 主档建议直接焊 1.35V；预留 DVFS 电阻位。
