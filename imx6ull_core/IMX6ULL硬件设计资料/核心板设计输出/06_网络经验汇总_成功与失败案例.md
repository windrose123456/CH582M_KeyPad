## 一、成功案例与可复用思路

### 1. 飞凌 FETMX6ULL-C 核心板（40×29mm）
**来源**：飞凌《第三代 i.MX6ULL 硬件设计指南及功耗表》；CSDN《i.MX6ULL核心板硬件设计：从功耗实测到底板避坑指南》（摘要）

**做法**：
- 核心板只放 CPU + DDR + eMMC + 电源，接口全走 BTB/连接器
- 官方给出**整板功耗实测表**（各场景 mA 级），底板电源按表设计
- 内部 PMIC LDO + 外部简单电源芯片协同，软件可控时序

**可学**：
1. 核心板「最小系统」边界清晰，底板才放 PHY/Codec/连接器
2. **先做功耗实测表再定底板电源**，不要拍脑袋
3. 对外文档给「底板设计避坑」清单 —— 我们 `02_BTB引脚定义.md` 同思路

### 2. 野火 EBF6ULL 三形态核心板（S1 邮票孔 / B1 BTB / F1 金手指）
**来源**：野火硬件文档 `doc.embedfire.com/linux/imx6/hardware/`

**做法**：
- 同一套核心电路做三种接口形态，**一份原理图/布线复用**
- BTB 版单独出《EBF6ULL BTB 核心板_PRO 开发板硬件手册》
- 配套 CE 检测报告 —— EMC 是产品化必过项

**可学**：
1. 接口形态可后定，核心电路先冻结
2. **BTB 公母、定位孔、高度要在手册里写死**
3. 邮票孔调试最方便，BTB 量产更专业 —— 你选了 BTB，建议再留邮票孔/测试点兜底

### 3. i.MX6UL / i.MX6ULL 共板设计
**来源**：CSDN《i.MX6 UltraLite 核心板设计实战：三种口味与底板开发全攻略》（摘要）

**做法**：
- UL / ULL **14×14 封装 pin-to-pin**，一块 PCB 贴不同型号 + 不同容量 DDR
- 528MHz / 792MHz / 900MHz 用不同供电档位

**可学**：
1. 你选的 **CVM08AB 与 EVK 的 DVM09AB 引脚兼容**，原理图可互换
2. 主频档 = **VDD_SOC_IN 电压档**（528→1.275V，792→1.35V，900→1.4V），FB 电阻留位

### 4. hceng「无资料裸机上手」方法论
**来源**：CSDN/hceng《iMX6ULL上手体验》（全文已读）

**做法**（拿到陌生板子的通用套路）：
1. 资料 = 参考手册 + 电路图（官网/厂家/网络三路）
2. 从 U-Boot 编译命令里**反推镜像加头方式**（`mkimage -T imximage` + `imximage.cfg`）
3. `imximage.cfg` 里 `DATA 4 0x021B0000 ...` **就是 DDR 初始化表** → 裸机也能用 DDR
4. 先点灯 → 串口 → 重定位 → printf

**翻车与修复（他的失败案例）**：
| 现象 | 原因 | 解决 |
|------|------|------|
| 串口打印 `45` 变成 `tu` | 波特率分频不准 | 程序里按实测改 125000 |
| 串口随机乱码/不打印 | **没做重定位**，跑在 SRAM 却按 DDR 链接地址取数 | `start.S` 里 relocate 到 0x80000000 |
| 工具链不支持硬件除法 | 裸机环境 | Makefile 加 `-lgcc` 或改常量 |

**可学**：
- **DDR 不是「玄学」**：U-Boot/`imximage.cfg` 的 MMDC 寄存器序列可直接抄到自己板（需按颗粒改）
- 链接地址 ≠ 运行地址 会「偶发」诡异错误 —— 调试裸机/改 U-Boot 时必查

### 5. 正点原子 / 百问网启动模式与量产
**来源**：51CTO《IMX6ULL启动流程》、CSDN 启动模式配置文（摘要）

**做法**：
- 拨码 BOOT_MODE + BOOT_CFG，默认 eMMC/SD，一键切 Serial Download
- 量产用 **Boot From Fuses**（去掉拨码电阻，降 SNVS 漏电）

**可学**：
- 与我们 `03_原理图设计笔记.md` 页 9 一致：**开发拨码、量产熔丝**

## 二、失败案例（避坑清单）

### 失败 1：DDR 调不通 / Linux 随机挂
**来源**：电子发烧友《i.mx6ul PCB》、电子工程世界 MMDC/DDR3 笔记、多方经验（摘要+已核对）

| 根因 | 表现 | 对策 |
|------|------|------|
| 拓扑错误 | 读写偶发错 | **单颗点对点**；双颗才 Fly-by（我们单颗 MT41K256M16，直连短线） |
| 等长/阻抗失控 | 压力测试不过 | DQ↔DQS ±5mil；ADDR↔CLK ±10mil；CLK/DQS 100Ω 差分 |
| VREF 不干净 | 低概率 bit 翻转 | 分压 + **0.22µF 紧贴**，短粗 |
| ZQ 电阻错 | 驱动校准失败 | **240Ω 1%** 紧贴 DRAM |
| 电源纹波 | 高负载挂 | 1.35V 纹波 ≤30–50mV，bulk 电容近颗粒 |
| DDR 类型配错 | U-Boot 起不来 | `imximage.cfg`/ddr.cfg 与颗粒 **DDR3 vs DDR3L vs LPDDR2** 一致（电压 1.5/1.35/1.2） |
| ODT/DSE 默认不适配 | 边缘稳定 | 软件可调；板级预留源端串阻 0–33Ω |

### 失败 2：以太网掉线 / 网络调不通
**来源**：CSDN《i.MX6ULL双网卡频繁掉线》《IMX6ULL网络调不通？LAN8720A排查》（摘要）

| 根因 | 表现 | 对策 |
|------|------|------|
| RMII **REF_CLK 波形差** | Link Up/Down 循环 | 50Ω、短、远离开关电源；示波器看眼图/边沿 |
| PHY **复位脚接错** | 驱动起不来 | 百问网把 LAN8720A RESET 接到 **SNVS_TAMPER6(GPIO5_IO06)**，与 NXP 官方不同 —— **必须跟自己原理图写 DTS** |
| PHY **地址电阻** | mdio 读不到 | LAN8720A 由 RXER/PHYAD0 上拉定地址 |
| 引脚驱动能力 | 时钟异常 | IOMUX DSE 调整 |
| DTS 与原理图不一致 | 百般调试无效 | 对照 PDF 原理图逐脚核 pinmux |

**教训**：厂商板与官方 EVK 的 **GPIO 分配经常不同**，抄 DTS 必须改 pinmux。

### 失败 3：无法启动 / U-Boot 不加载
**来源**：正点原子论坛《M6ULL一直进不去》、《启动失败：SD卡识别正常但U-Boot不加载》（摘要）

| 根因 | 检查 |
|------|------|
| BOOT_MODE/BOOT_CFG 拨码错 | 上电前用万用表确认 0/1 |
| 镜像没加 imx 头 / 偏移错 | SD/TF 裸机与 U-Boot 都在 **偏移 1KB（seek=2 扇区）** |
| POR_B 未释放 | 示波器 |
| 24MHz 未起振 | 示波器/逻辑分析仪 |
| DDR 初始化失败 | U-Boot 卡在早期；用 Serial Download 先验证 CPU |
| 电源时序 | SNVS→HIGH→SOC |

**正点原子论坛建议**：BGA 底部信号测不到时，**测外围可测点 + 对比原理图网络**，再不行找厂商要底层原理图。

### 失败 4：电源 / 工业接口翻车
**来源**：CSDN《i.MX6ULL终结者硬件设计避坑指南：从电源防反接到485自收发》（摘要）

| 坑 | 对策（写入我们底板规范） |
|----|------------------------|
| 5V 反接烧板 | 防反接 MOS/二极管 + TVS |
| 宽压输入 | 前级 DCDC/BUCK 耐压留裕量 |
| RS485 自收发冲突 | 收发控制脚或自动收发电路要验证 |
| 热插拔 | VBUS 负载开关限流 |

### 失败 5：ADC / 设备树配置
**来源**：CSDN《IMX6ULL ADC踩坑实录》《设备树避坑：pinctrl》（摘要）

| 坑 | 对策 |
|----|------|
| `num-channels` 默认只 2 通道 | DTS 按实际改 |
| 改了 `imx6ull.dtsi` 不生效 | **板级 dts** 才是编译入口，确认改对文件 |
| ADC_VREFH 悬空 | 不用 ADC 也要 **VDDA_ADC_3P3 供电**，VREFH 短到 VDDA |

### 失败 6：JTAG / 调试
**来源**：电子技术论坛 openocd 调试帖；NXP datasheet（已核对）

| 坑 | 对策 |
|----|------|
| JTAG_TDO 外加上拉 | **禁止**（片内 Keeper） |
| JTAG_MOD 悬空 | 正常调试 **接地** |
| openocd 需专用 cfg | `imx6ull_ddr.cfg` 等，可参考社区 |

## 四、心法提炼（他山之石）

1. **「先抄后改」是行业共识**  
   飞凌/野火/正点原子全部从 NXP EVK 演化。我们 `03_原理图设计笔记.md` 逐页对 `SPF-29364_B1.pdf` 是正确路径。

2. **电源是一版成的命门**  
   失败帖里「无法启动/发烫/随机挂」最后多半回到：时序、纹波、\*_CAP 误供电、VDDA 没电。

3. **DDR 失败 ≠ 布线一定错**  
   顺序排查：电压/纹波 → VREF/ZQ → 等长阻抗 → ddr.cfg 颗粒参数 → ODT/DSE/串阻。先降频验证。

4. **原理图与 DTS 必须「同一真相」**  
   网络调不通、ADC 读不到，大量是 **GPIO 分配与设备树不一致**。BTB 引脚表要作为软硬件共同契约。

5. **救砖通路比性能接口优先**  
   所有成功板子都保证：**UART + USB Serial Download + BOOT 拨码**。没有这三样，BGA 板等于一次性彩票。

6. **接口形态可以晚定，机械要早定**  
   野火三形态同核心；BTB 的 **定位孔/高度/防呆** 不定，核心板画完也会和底板对不上。

7. **留测点、留 DNP、留串阻位**  
   社区翻车板很多靠飞线/换电阻救回 —— 原理图阶段就要留。

8. **功耗/热**  
   飞凌出功耗表、NXP 出 AN5345：792MHz 满载 VDD_SOC 约 200mA+，视频场景 DDR 侧可达 120mA —— 电源选型别贴极限。
