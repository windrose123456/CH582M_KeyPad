## 2. 焊接与上电前

1. **目检**：BGA 用 X-Ray 或侧光看连锡/虚焊；极性件方向；BTB 平行度。
2. **阻抗（万用表二极管档/电阻档）**：
   - +3.3V / +1.35V_CPU / +1.35V_DRAM / +1.8V 对 GND：不应接近 0Ω（几 Ω 以上）
   - 若 <2Ω：先找短路（电容、BGA 连锡、FB 电阻焊错）
3. **确认 DNP**：QSPI 不贴可先不管；测流电阻 = 0Ω。

## 3. 上电调试顺序

### Step 1 电源时序（示波器，单次触发）

按顺序抓：

| 探头 | 期望 |
|------|------|
| VDD_SNVS_IN | 最先建立 3.3V，平稳 |
| DCDC_3V3 | 其次 3.3V，PG 变高 |
| VDD_SOC_IN (1.35V) | PG 后建立 |
| NVCC_DRAM (1.35V) | 与 SOC 类似 |
| POR_B | **保持低**直到全部稳定，再释放（上升） |

不合格：检查使能链、RC 延时、UM803 阈值。

### Step 2 时钟

| 项目 | 期望 |
|------|------|
| 24MHz | 起振、正弦/削波正常、频偏 <50ppm（USB 要更严） |
| 32.768kHz | 起振（高阻探头） |

不起振：负载电容、ESR、布线寄生、晶振方向。

### Step 3 电流初值

| 状态 | 大致电流 |
|------|---------|
| 仅 SNVS | µA 级 |
| 上电未启动 | 几十 mA |
| Boot ROM 跑 | 50–150 mA |
| 死短 | >500 mA 或熔断 |

### Step 4 USB Serial Download（救砖通路验证）

1. BOOT_MODE = `01`（Serial Downloader）
2. 接 OTG1 到 PC
3. 上电 → `uuu` 或 NXP mfgtool **能识别设备**
4. 识别成功 = CPU / 时钟 / 复位 / USB PHY / 供电基本 OK

### Step 5 UART 启动日志

1. BOOT_MODE = `10`，从 eMMC 或 SD 启动
2. UART1 115200-8-N-1
3. 看到 **Boot ROM / U-Boot 打印** = 最小系统 OK
4. 无打印：查 UART 引脚/BTB、波特率、POR、BOOT 模式

### Step 6 DDR

```
# U-Boot
mtest 0x80000000 0x1000 0x0 100   # 按实际容量
md 0x80000000 0x100
```
- 报错/死机：VREF、1.35V 纹波、等长、ZQ、ODT/DSE（软件调）
- 可先降频（396 MHz）验证

### Step 7 eMMC

```
mmc dev 0
mmc info
# 烧写系统后
boot
```
- 识别失败：VCC/VCCQ、上拉、USDHC 口、上电顺序

### Step 8 外设递进

UART → SD/TF → USB Host → ENET ping → LCD → CAN → 低功耗（suspend/SNVS）

## 4. 故障速查

| 现象 | 优先排查 |
|------|---------|
| 上电无电流 | 5V 入口保险/反接；VDD_SNVS 是否最先；EN 悬空 |
| 电流大 / 发烫 | 短路；TEST_MODE 未接地；\*_CAP 误供电；BGA 连锡 |
| 电源电压错 | FB 电阻值/虚焊；电感值；芯片使能 |
| 时序错 | PG 级联；RC 延时；UM803 阈值 |
| 无串口 | 24M 未起振；POR_B 未释放；UART 脚/BTB；BOOT 模式 |
| USB 识别不了 | 24M 频偏/抖动；BOOT_MODE=01；D+/D- 反；串阻/TVS 焊错 |
| U-Boot 有、DDR 报错 | VREF；等长/阻抗；ZQ；电源纹波；ODT |
| eMMC 不识别 | VCC/VCCQ；CMD 上拉；CLK 线；USDHC 口 |
| Linux 随机挂 | 纹波（<30–50mV）；去耦；地缝；DDR 时序 |
| 以太网不通 | REF_CLK 50M 从 PHY；MDIO 上拉；变压器中心抽头 |
| 背光/屏无显示 | LCD_PWM 频率；BL_EN；数据位宽配置 |
| 关机 RTC 不走 | 纽扣电池/防倒灌；VDD_SNVS；32k 晶振 |
| 发热严重 | 电压设太高；DCDC 效率；散热过孔；负载短路 |

## 5. 纹波与功耗参考（AN5345 实测）

| 工况 | VDD_SOC_IN | VDD_HIGH_IN | NVCC_DRAM+颗粒 |
|------|------------|-------------|----------------|
| Deep Sleep | 0.25 mA @0.92V | 0.1 mA | 7.6 mA |
| Idle | 3.8 mA | 1.3 mA | 8 mA |
| Dhrystone 800MHz | 225 mA @1.38V | 15 mA | 10 mA |
| 视频重载 800MHz | 190 mA | 23 mA | 120 mA |
| SNVS only | 0 | 0 | 0（SNVS 25µA） |

**电源纹波目标**：≤30mV（核压）、≤50mV（IO）。

**DDR ODT / DSE**：功耗与稳定性强相关；BSP 默认值按板长微调。

## 6. 一版成兜底（改版飞线预案）

| 问题 | 可救手段 |
|------|---------|
| 核心电压偏 | 改 FB 电阻 |
| DDR 边缘不稳 | 调 ODT/DSE；串阻位改 0–33Ω |
| eMMC HS200 不稳 | VCCQ 切 3.3V 降速 |
| BOOT 电阻焊错 | 拨码强制 Serial Download 重烧 |
| 某 LDO 坏 | 飞线替代 SOT-23-5 |
| BTB 某脚虚焊 | 对面测试点飞线到底板 |
