# PCB 层叠 / 阻抗 / 布局规则

> 对照 `REF-29364_B.pdf`（EVK 布局参考图）与 LAY-29364_B.zip。
> **出图前用嘉立创阻抗计算器重算线宽线距，并回写规则。**

---

## 1. 板框与层叠

### 1.1 板框

| 项目 | 建议 |
|------|------|
| 尺寸 | 45–55 × 40–50 mm（BTB 双侧时略呈矩形） |
| 板厚 | 1.2mm（BTB 高）或 1.6mm（标准） |
| 元件面 | 尽量单面贴：顶面 CPU/DDR/eMMC/电源/晶振；底面 BTB |
| 安装孔 | 4×M2.5，与底板对齐 |
| 工艺 | 嘉立创 4 层：最小线宽/孔 3.5/3.5mil 可做 0.8mm BGA；0.5mm BTB 用 4/4mil 足够 |

### 1.2 推荐 4 层（EVK 验证）

```
L1  TOP      信号：CPU 扇出、DDR、USB/ETH/LCD 高速、晶振
L2  GND      完整地平面（禁止分割、禁止走线）
L3  PWR      电源分区：+1.35V_CPU | +1.35V_DRAM | +3.3V | +1.8V
L4  BOTTOM   一般信号、BTB 扇出、少量电源
```

| 介质（典型 1.6mm 4L） | 厚度 |
|---------------------|------|
| L1 Cu | 1 oz (35µm) |
| PP / 芯板 | 0.1–0.2mm（控制 L1↔L2 耦合） |
| L2 Cu | 1 oz |
| 芯板 | 0.8–1.0mm |
| L3 Cu | 1 oz |
| PP | 0.1–0.2mm |
| L4 Cu | 1 oz |

### 1.3 备选 6 层（DDR 等长/阻抗不够时）

```
L1 SIG / L2 GND / L3 SIG(内) / L4 PWR / L5 GND / L6 SIG
```
DDR 放 L1，参考 L2；内层 L3 可走 ADDR 等长。

## 2. 阻抗与线宽（**用 JLC 计算器覆核后填实际值**）

| 信号 | 目标阻抗 | 参考层 | 典型线宽/线距（1.6mm 4L，需重算） |
|------|---------|--------|----------------------------------|
| DDR DQ/ADDR/CMD/CLK_SE | 50Ω SE | L2 GND | ~4–5 / 6–8 mil |
| DDR DQS/DQS#、CLK_P/N | 100Ω diff | L2 GND | 对内 5 mil gap 量级 |
| USB DP/DM | 90Ω diff | L2 GND | |
| ETH RMII、LCD、CSI | 50Ω SE | L2 GND | |
| 普通 GPIO/UART/I2C | 不控 | — | 6 mil |
| 电源主干 | — | — | ≥15 mil/A；3A 级用 40–60 mil 或铺铜 |

**规则管理器建议**：

| 类 | 包含网络 | 线宽 | 线距 | 等长 |
|----|---------|------|------|------|
| DDR_DQ0 | DQ[0:7], DQS0*, DM0 | W50 | S8 | ±5 mil vs DQS0 |
| DDR_DQ1 | DQ[8:15], DQS1*, DM1 | W50 | S8 | ±5 mil vs DQS1 |
| DDR_ADDR | A*, BA*, RAS, CAS, WE, CS, ODT, CKE | W50 | S8 | ±10 mil vs CLK |
| DDR_CLK | CLK_P/N | 100Ω | 对内 ±5 mil | |
| USB | DP/DM | 90Ω | 对内 ±5 mil | |
| ETH_RMII | ENET* | W50 | S8 | 组内 ±50 mil |
| POWER | 电源网络 | 20–60 mil | — | — |

## 3. 布局（对照 REF-29364_B.pdf）

```
        ┌──────── BTB J2（LCD/CSI）────────┐
        │  晶振   eMMC    CPU     DDR3L    │
        │   Y1     U3     U1      U2       │
        │  电源 DCDC 群                      │
        └──────── BTB J1（调试/USB/ETH）────┘
```

| 器件 | 位置 |
|------|------|
| CPU U1 | 板中心偏 BTB 中央；BGA 扇出两圈 via |
| DDR3L U2 | **CPU 同侧紧贴**，球对球距离最短 |
| eMMC U3 | CPU 同侧或正背面，USDHC2 扇出短 |
| 电源 IC | 板角/边，电感远离晶振与 DDR |
| Y1 24MHz | 紧贴 XTAL 球，包地过孔 |
| Y2 32.768kHz | 紧贴 RTC 球，与 Y1 隔离 |
| 去耦 100nF | **贴 BGA 焊盘**（扇出内侧） |
| 22µF/10µF | CAP 脚与电源入口旁 |
| BTB | 长边；J1 朝调试侧、J2 朝屏/相机侧 |
| 测试点 | 板边一圈：电源、POR、24M、UART、BOOT |

## 4. 布线细则

### 4.1 BGA 扇出（0.8mm pitch）

- via：盘 0.45mm / 孔 0.2–0.25mm（JLC 4L 可做）；或盘 0.5 / 孔 0.3
- 外两圈 dog-bone 外扇；内圈盘中孔（可选，成本↑）
- 电源/地球优先打孔到 L3/L2
- **中心热焊盘区**：阵列过孔到 L2 GND + 顶/底铺铜

### 4.2 DDR 优先级

1. CLK_P/N 差分对 → 最短、对称、参考 L2 不间断
2. DQS0/DQS1 差分对
3. DQ 组内等长（蛇形在源端 2×线宽以外，振幅 < 3×线宽）
4. ADDR/CMD 与 CLK 等长
5. 过孔数同组一致（同组同层）
6. 不跨 L3 电源分割；换层打回流地 via
7. 不直角；圆弧/45°
8. VREF 短粗 + 0.22µF 紧贴 CPU/DRAM 分压点

### 4.3 高速接口

| 接口 | 要求 |
|------|------|
| USB | 90Ω 差分，不打孔优先，包地 |
| ETH RMII | 50Ω，REF_CLK 等长到 PHY 座 |
| LCD/CSI | 同组等长 ±50 mil，CLK 单独 50Ω |
| 晶振 | 包地 + 两侧地 via；禁其它信号穿过下方 |

### 4.4 电源

- L3 分区矩形，缝宽 ≥ 20 mil
- DCDC 开关节点（SW）**极短**、铺铜最小化，电感另一侧
- 功率路径：输入电容 → IC → 电感 → 输出电容，**单点回流**
- 每 NVCC 球 100nF；每轨 bulk 10–22µF
- 5V 入口：≥40 mil 或 2 层并联到 DCDC

### 4.5 EMC

- BTB 周围 GND via 护栏（间距 ≤ λ/20）
- 板边地铜完整
- 对外 IO 预留 TVS 位（底板装）
- 丝印：Pin1、极性、版本、日期

## 5. 布局布线顺序（D6–D8）

| 步 | 动作 |
|----|------|
| 1 | 板框 + BTB + 安装孔 + 禁布区 |
| 2 | CPU / DDR / eMMC / 电源 / 晶振定位 |
| 3 | BGA 扇出 |
| 4 | 电源平面与去耦 |
| 5 | DDR CLK → DQS → DQ → ADDR（等长） |
| 6 | USB / ETH / LCD |
| 7 | BTB 扇出与组内等长 |
| 8 | 铺铜、地 via、丝印、测试点 |
| 9 | DRC + 阻抗表 + 3D BTB 对位 |
